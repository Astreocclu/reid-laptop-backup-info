Reid Laptop Backup

A personal backup utility for the account owner's laptop and Linux migration. Local restic and rclone tools encrypt selected files before storing backup objects in the owner's Google Drive.

The utility requests only the Google Drive drive.file permission for files used with this app. It is not offered as a public backup service. This website does not sign users in, receive backup data, or provide downloads of backups.
